# Code of Conduct

## Our Standards

This project should be a respectful, practical place to collaborate. Contributors are expected to:

- Be considerate and professional.
- Focus feedback on the work, not the person.
- Assume good intent while still being clear about technical concerns.
- Respect privacy and avoid sharing another person's private data.

Unacceptable behavior includes harassment, threats, discriminatory language, unwanted sexual attention, doxxing, or deliberately disruptive conduct.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, block accounts, or take other reasonable action when behavior harms the project or its contributors.

If you need to report a conduct issue, contact the maintainer privately. Include relevant links, screenshots, or context when possible.
