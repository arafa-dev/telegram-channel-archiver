# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

If you find a security issue, email the maintainer or use GitHub private vulnerability reporting if it is enabled for the repository. Include:

- A clear description of the issue.
- Steps to reproduce it.
- The affected commit, version, or branch.
- Any relevant logs or screenshots with private data removed.

## Scope

Security reports are especially useful for issues involving:

- Unauthorized access to local files, browser storage, or Telegram account data.
- Overbroad Chrome extension permissions.
- Unexpected network requests.
- Download path traversal or unsafe filename handling.
- Exposure of private Telegram data in logs, archives, issues, or pull requests.

## Handling Private Data

Do not include Telegram messages, media, account details, cookies, tokens, browser profiles, or downloaded archives in public issues or pull requests.
